ALMOGHANI PWA
==============
هذه الملفات لا تغيّر تصميم موقعك.

1) ارفع هذه الملفات بجانب index.html:
   manifest.webmanifest
   sw.js
   icon-192.png
   icon-512.png

2) افتح ADD_TO_YOUR_HTML.txt.
3) انسخ جزء <head> إلى داخل <head> في صفحتك.
4) انسخ كود <script> قبل </body>.
5) استبدل الأيقونات لاحقاً بأيقونتك بنفس الأسماء والمقاسات.

على iPhone:
افتح الموقع في Safari > مشاركة > إضافة إلى الشاشة الرئيسية.
